
## 2026-07-20 DMG 版本号与 git tag 不一致修复
- 现象：打 tag v0.1.0-beta2 后，release 里的 dmg 文件名却是 Blink-0.1.0-beta1-*.dmg。
- 根因：Wails 版本号来自 build/config.yml 的 info.version（"0.1.0-beta1"），经 build/darwin/Info.plist 的 CFBundleShortVersionString 写入 dmg 文件名（darwin:create:dmg 任务读取该字段）。git tag 与 Wails 版本号是两个独立来源，release-dmg.yml 从未把 tag 同步进版本号，故产物挂在 beta2 release 下却叫 beta1。
- 修复：release-dmg.yml 新增 "Sync version from tag" 步骤（在 wails3 task darwin:dmg 前），用 sed 把 tag（去 v 前缀）写入 config.yml 的 version，用 plutil 改 Info.plist/Info.dev.plist 的 CFBundleShortVersionString；workflow_dispatch 增加 version 输入。只改版本号字段，不重新 generate assets（避免覆盖之前方案A的图标修复）。
- 遗留：已发布的 v0.1.0-beta2 release 内 dmg 文件名仍为 beta1，需重新发版（建议直接发 beta3）才能修正。本地 config.yml 仍是 beta1，下次本地 build 仍生成 beta1（正常，本地开发无碍）。

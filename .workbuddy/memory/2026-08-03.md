# 2026-08-03 — Blink Windows 适配

延续此前会话，完成 Blink（macOS 菜单栏护眼 App，Wails v3）的 Windows 适配。
macOS 作为稳定基线，本会话只动 Windows 路径。

## 已完成（5 项任务全绿）
1. **平台层**（前会话）：`internal/platform/` 新增 `idle_windows.go`（GetLastInputInfo+GetTickCount64，32位回绕用 uint32 截断）、`sound_windows.go`（winmm PlaySoundW）、`activation_windows.go`（ForceForeground 用 AttachThreadInput 抢占前台）；构建约束拆分 darwin/windows/other。
2. **关闭确认弹窗（重点诉求）**：`prefs_close_windows.go` 用 `w.RegisterHook(events.Common.WindowClosing, ...)` 同步否决关窗事件 → goroutine 中按 `CloseAction` 分流；`askAndHandleClose` 用 `app.Dialog.Question()`（非 `application.QuestionDialog()`，后者不存在）弹 MB_YESNO，按钮必须写 "Yes"/"No"（Wails 把返回值映射回这两个字符串匹配 Button.Label）。默认选中 Yes（保留后台）。`prefs_close_other.go` 为空操作。
3. **main.go/tray**：`Windows: application.WindowsOptions{DisableQuitOnLastWindowClosed: true}`；`tray_platform_windows.go` 嵌入 icon.ico、绑定 OnClick=OpenMenu、OnDoubleClick=showPreferences。
4. **窗口显示**：`window_options.go` 给 overlay/notice 加 `Windows: application.WindowsWindow{HiddenOnTaskbar:true, DisableFramelessWindowDecorations:true}`。关键：Windows 非实色背景走 WS_EX_NOREDIRECTIONBITMAP（仍接收鼠标），只有 `IgnoreMouseEvents` 才加 WS_EX_TRANSPARENT（点击穿透）；故 notice 的"推迟"按钮在 Windows 上可用。
5. **快捷键平台化**：新建 `frontend/src/lib/platform.ts`，用 `window._wails.environment.OS`（回退 userAgent）检测平台；`KeyRecorder.vue` 与 `useShortcutsConfig.ts` 的修饰键/占位符按平台切换（macOS Cmd/Option，Windows Ctrl/Alt）。metaKey 在 Windows 归并到 Ctrl（避免 Win+ 被系统占用、且 "win" 非合法 token，合法的是 "super"）。

## 追加：关闭确认弹窗改用 Vue 前端组件（用户要求"弹窗可以用 vue 啊"）
- **原方案**用 Wails `app.Dialog.Question()` → Windows MessageBox，无法加"记住我的选择"复选框，按钮文字也不能本地化（必须硬写 "Yes"/"No"）。改为前端 Vue 弹窗后这些限制全部消失。
- **Go 端**：新建跨平台 `prefs_close.go`（状态机 + 动作执行）；`prefs_close_windows.go` 改为 `app.Event.Emit("blink:close-request")` 发事件给前端（不再弹原生对话框）；`breakservice.go` 新增 `ResolveClose(action, remember)` 和 `AckClose()` 绑定方法。
- **关键设计：两步握手防误判**。Go 端 `beginCloseAsk()` 挂 4s 兜底定时器（防前端无响应导致关闭按钮永久失灵）；前端收到事件立刻调 `AckClose()` 停表（只停定时器、不结束询问）；用户做决定后调 `ResolveClose()`。这样超时只衡量前端响应能力，不把用户思考时间算进去——否则用户盯着弹窗 4 秒后窗口会自己消失。
- **快照同步**：`useEngineState` 新增 `applyExternal(patch)`，在弹窗"记住选择"写 `closeAction` 时同时更新 `savedSnapshot`，否则用户之后改别的设置一保存就会把后端刚存的值覆盖回旧值。
- **前端组件**：`CloseConfirmDialog.vue`（玻璃拟态模态框，含说明、勾选框、保留后台/完全退出/取消三操作，ESC 与点遮罩取消）。
- **bindings 生成**：`wails3 generate bindings -f '' -clean=true -ts -i`（`$Call.ByID(hash)` 的 hash 不能手写，必须靠生成器）。注意 `-clean` 删目录重建有竞态，生成后需二次确认函数已写入。退出码始终为 1 但输出正常（wails3 CLI 已知行为）。
